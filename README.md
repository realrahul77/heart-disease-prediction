# ❤️ Heart Disease Risk Prediction System

A Machine Learning web application that predicts the likelihood of heart disease using a **Random Forest Classifier** trained on the **UCI Heart Disease Dataset**.

## 📌 Features

- Predicts heart disease risk from clinical parameters
- Clean and responsive user interface
- Flask-based web application
- Random Forest Machine Learning model
- Data preprocessing using Scikit-learn Pipeline
- Educational and internship demonstration project

## 🛠 Tech Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Scikit-learn
- Pandas
- NumPy

## 📂 Dataset

**UCI Heart Disease Dataset**

- Total Records: **920**
- Clinical Features: **13**
- Target Classes:
  - 0 → Low Risk
  - 1 → High Risk

## 🤖 Machine Learning

Algorithm Used:

- Random Forest Classifier

Model Accuracy:

**85.87%**

